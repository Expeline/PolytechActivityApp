# Политех 3.0

Расписание СПбПУ для iPhone, iPad и Mac. Без входа в личный кабинет, без рекламы и аналитики. Стартовая группа — **5130904/40102 (ИКНК)**, её можно поменять в настройках.

Android-версия живёт в отдельном репозитории: [PolytechActivityAndroid](https://github.com/Expeline/PolytechActivityAndroid). Обе версии работают с одним и тем же сервером.

## Что умеет

**Расписание.** Текущая или следующая пара с таймером — в приложении, в Live Activity и Dynamic Island, в виджетах iPhone, iPad и Mac, в строке меню Mac. Сохраняется до 12 недель вперёд, так что всё работает и без интернета. Время всегда московское.

**Задания группы (PolyStudy).** Кто-то из группы публикует домашку — она появляется у всех, кто выбрал эту группу. Задание привязано к предмету, срок по умолчанию — начало следующей пары по нему. Отметка «сделал» у каждого своя, группа видит только сколько человек уже справились. Напоминания приходят за день и за три часа до срока. Без сети всё сохраняется и уходит на сервер, когда связь появится.

**История изменений (PolyChanges).** Приложение само замечает, что пару перенесли, отменили, добавили новую или поменяли аудиторию либо преподавателя. В расписании на таких парах появляются метки, отменённая пара остаётся на своём месте зачёркнутой, а в карточке занятия видно, что было и что стало. Это работает даже без сервера. Сервер дополнительно проверяет расписание каждые 15 минут, даже когда телефон в кармане.

**Остальное.** Можно пропускать лекции или военную подготовку (целиком, по предмету или одну пару), завершить учебный день кнопкой, выбрать тему, один из девяти акцентных цветов и масштаб текста.

### Как выглядит

Под заголовком — переключатель **Расписание · Задания · Изменения** (на Mac — ⌘1, ⌘2, ⌘3). Числа на нём показывают срочные задания и непросмотренные изменения. Под карточкой текущей пары — три плитки: сколько пар сегодня, что сдавать в ближайшие дни, что поменялось. В списке пар видны перерывы и линия «сейчас».

Дизайн подстроен под iOS 27: плавающие элементы (переключатель разделов, кнопка настроек) сделаны из Liquid Glass, а карточки с расписанием остались плотными — так текст проще читать. Переключение разделов анимировано, отметка задания отзывается вибрацией.

## Как всё устроено

```
iPhone · iPad · Mac  ──┐
                       ├── HTTP + WebSocket ──▶  PolyServer (Swift, Vapor)  ──▶  PostgreSQL
Android ───────────────┘                               │
                                                       └──▶ API расписания РУЗ СПбПУ
```

- `App/`, `Mac/`, `Widgets/`, `LiveActivity/` — приложения на SwiftUI.
- `Shared/` — общий код: модели, клиент API РУЗ, сравнение расписаний. Его используют и приложения, и сервер.
- `Server/` — сервер на Vapor 4 с PostgreSQL.
- `Tests/` — тесты общего кода, `Server/Tests/` — тесты сервера.

Логина и паролей нет. При первом подключении устройство получает от сервера случайный ключ и хранит его в Keychain, на сервере лежит только его хэш. В настройках можно указать имя, под которым тебя увидят одногруппники.

Задания открыты всем, кто выбрал группу. Чтобы этим не злоупотребляли: править и удалять задание может только автор, после трёх жалоб оно скрывается у всех, а с одного устройства можно опубликовать не больше 30 заданий в час.

## Запуск на своём компьютере

Понадобится Mac с **Xcode 27** и **Homebrew**. Если хочется проверить только приложение без общих заданий, сервер можно не поднимать: расписание и история изменений работают и без него.

### 1. Сервер и база данных

```sh
git clone https://github.com/Expeline/PolytechActivityApp.git
cd PolytechActivityApp
Scripts/server_setup.sh
```

Скрипт поставит PostgreSQL через Homebrew (если его ещё нет), запустит его, создаст базы `polytech` и `polytech_test` и подготовит таблицы. Первый раз это займёт пару минут: Swift скачивает и собирает Vapor.

Затем запускаем сервер:

```sh
cd Server
swift run PolyServer serve
```

Сервер слушает порт **8080**. Проверить, что он жив: `curl localhost:8080/v1/health` должен ответить `{"status":"ok"}`. Остановить — `Ctrl+C`.

Если нужно что-то поменять, есть переменные окружения: `DATABASE_URL` (по умолчанию `postgres://$USER@localhost:5432/polytech`), `PORT` (8080) и `WATCH_INTERVAL` — как часто проверять расписание, в секундах (900).

### 2. Приложение для Mac

Открой `Polytech.xcodeproj`, выбери схему **PolytechMac** и **My Mac**, нажми **⌘R**. Mac-версия сама найдёт сервер на `http://localhost:8080`.

### 3. Приложение для iPhone или iPad

1. В Xcode выбери схему **Polytech** и свой iPhone.
2. Если Xcode попросит подпись: синий значок проекта → **TARGETS → Polytech → Signing & Capabilities** → своя **Personal Team**. То же самое для **PolytechLiveActivity**.
3. Подключи и разблокируй телефон, подтверди доверие компьютеру, нажми **⌘R**.
4. Если попросит — включи на телефоне **Настройки → Конфиденциальность и безопасность → Режим разработчика**.
5. В приложении открой **Настройки → Задания и изменения → Сервер группы** и впиши адрес своего Mac: `http://ИМЯ-MAC.local:8080`. Имя можно узнать командой `scutil --get LocalHostName`. Телефон и Mac должны быть в одной Wi-Fi-сети. Когда iOS спросит про доступ к локальной сети — разреши.

В симуляторе сервер доступен как `http://localhost:8080`, там ничего вписывать не нужно.

С бесплатной Personal Team приложение нужно переустанавливать через Xcode раз в 7 дней — [так устроено у Apple](https://developer.apple.com/help/account/basics/about-your-developer-account). Настройки и группа при переустановке сохраняются.

### 4. Тесты

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift test                       # общий код: модели, сравнение расписаний
(cd Server && swift test)        # сервер, нужна база polytech_test из шага 1
python3 Scripts/verify_builds.py # проверка собранных приложений и расширений
```

## Ограничения

- **Нет push-уведомлений.** Для них нужен платный аккаунт разработчика Apple. Уведомления о переносах и сроках локальные: они приходят, когда приложение обновило расписание, то есть при открытии или в фоне, когда iOS сочтёт нужным.
- **Сервер пока живёт на твоём Mac.** Если Mac выключен, задания копятся на телефоне и отправятся позже. Чтобы группа пользовалась сервером из любой точки, его надо перенести на VPS с HTTPS — код к этому готов, нужна только машина.
- Таймер Live Activity система отсчитывает сама, а вот переключение на следующую пару iOS делает при открытии приложения или в фоне, не секунда в секунду.

## API сервера

Все запросы идут на `/v1`, ключ устройства передаётся в `Authorization: Bearer …`.

| Что | Запрос |
| --- | --- |
| Зарегистрировать устройство | `POST /devices` |
| Сменить имя | `PATCH /devices/me` |
| Подключиться к группе / отключиться | `PUT` / `DELETE /groups/:id/subscription` |
| Задания группы (с `?since=` — только новые) | `GET /groups/:id/assignments` |
| Опубликовать задание | `POST /groups/:id/assignments` |
| Изменить / удалить своё | `PATCH` / `DELETE /assignments/:id` |
| Отметить выполненным / снять отметку | `PUT` / `DELETE /assignments/:id/completion` |
| Пожаловаться | `POST /assignments/:id/report` |
| История изменений расписания | `GET /groups/:id/changes` |
| Живые обновления | WebSocket `GET /groups/:id/live` |

Даты передаются в миллисекундах с 1970 года. Подробный формат описан в `Shared/PolyModels.swift`.
